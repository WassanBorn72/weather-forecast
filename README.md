# Weather Weave — 比べて、わかる天気。

複数の数値予報モデルの見通しを並べ、地点・予報の先の時間・気象変数ごとの過去の誤差から統合するWebアプリです。独自予報が優れると決めつけず、単独モデルと単純平均を比較します。現在はPhase 1のMVPです。

## 利用するモデルとデータ

Open-Meteo経由でJMA GSM、ECMWF IFS 0.25°、GFS Global、ICON Globalを取得します。モデル・地点・変数・期間によって欠測があります。JMA／ECMWFの降水確率など未提供の値は「—」となり、降水量から確率を捏造しません。モデルの降水確率は提供元のアンサンブル由来の派生量であり、決定論モデル固有の確率とは限りません。

現在表示は最新の時間別**モデル予報**です。気象観測を定期取得する機能は未接続で、実測の現在天気とは表示しません。過去予報にはSingle Runs API、24時間単位の診断にはPrevious Runs APIを使用します。実測は出典と地点を指定したCSVから取り込みます。NOAA公式観測APIからの手動取得アダプターも用意していますが、この環境での実応答検証は接続許可待ちです。再解析を実測として扱いません。

データ提供： [Open-Meteo](https://open-meteo.com/) および [各モデル提供機関](https://open-meteo.com/en/licence)。データはCC BY 4.0に基づき出典を表示し、本アプリで統合・加工します。無料APIは非商用に限られ、広告・販売等には契約が必要です。条件と確認根拠は [データソース](docs/data-sources.md) を参照してください。

## 統合予報と信頼度

データが足りない間は単純平均です。実測との比較が揃うと最近の誤差を重視した重み付き平均を使います。各変数・地点・季節・リードタイムで重みを別に計算し、重み・標本数・理由を確認できます。風向は円周平均、天気状態は重み付き投票です。

信頼度はモデル間のばらつき、過去の誤差、予報の先の時間、標本数を踏まえた目安です。表示する誤差幅は統計的に校正された予測区間ではありません。未検証なら「低」と表示します。安全判断には気象庁の防災情報も確認してください。

## インストールと実行

Node.js 24.5以上（環境プロキシ対応の開発APIを使うため）を使用します。

```sh
npm ci
npm run db:migrate
npm run setup:dev
npm run dev:api
# 別のターミナル
npm run dev
```

東京などの地点を選び「実データ」を押すとモデルを取得します。APIに接続できない場合も、勝手に実データをサンプルへ切り替えません。「デモ」で明示的な合成データを使い、画面と計算を確認できます。デモの精度や重みは実際のモデル性能を表しません。観測CSVの取り込みなど管理機能には`npm run setup:dev`で既存ファイルを保持して生成する`.dev.vars`の`ADMIN_TOKEN`を使い、画面のデータ管理欄で入力します。トークンはブラウザに保存しません。

```sh
npm test
npm run build
npm run test:ui
npm run test:pwa
```

## AndroidなどでPWAとして使う

HTTPSで公開したページをChromeで開き、メニューの「ホーム画面に追加／アプリをインストール」を選択します。画面と直前に取得した予報をオフラインで閲覧できます。オフラインでは更新されず、取得時刻と古い予報である旨を表示します。開発時にService Workerは登録しません。
